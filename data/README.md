# Data

`bank-additional-full.csv` is the *Bank Marketing* dataset (5.8 MB, semicolon-separated), committed to the repo
so the dashboard works online without downloading anything.

- Original source: UCI Machine Learning Repository, https://archive.ics.uci.edu/dataset/222/bank+marketing
- Citation: Moro, S., Cortez, P., & Rita, P. (2014). A data-driven approach to predict the success of bank
  telemarketing. *Decision Support Systems*, 62, 22–31.
- 41,188 rows × 21 columns, May 2008 to November 2010, in date order.
